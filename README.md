# Personal Portfolio Website

## About the Project

This project is my personal portfolio website for the Web Programming final project.  

I tried to use the technologies we learned during the semester such as HTML, CSS, JavaScript, PHP, and MySQL. The project is not only a static website, because some parts of it are connected to a database.

## Technologies I Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- AJAX / Fetch API
- XAMPP
- phpMyAdmin

## Main Features

- Responsive personal portfolio design
- Desktop navigation menu
- Dark mode toggle
- Contact form
- JavaScript form validation
- Contact messages are saved into a MySQL database
- Projects are fetched from the database
- AJAX is used to load projects without refreshing the page

## Sections of the Website

The website includes these main sections:

- Home / Profile
- About Me
- Experience
- Projects
- Contact

The Experience section is currently used as a placeholder because I do not have professional work experience yet. I plan to update this section in the future when I gain internship or job experience.
